# Procrastibaker Design System

Brand feel:
- Cozy
- Warm
- Bakery-themed
- Playful but still usable
- Student-friendly
- Polished, not childish

Core colours:
- Cream: #FFF7DF
- Paper: #FFFAF0
- Bakery Orange: #E89D46
- Butter: #FFD76A
- Honey: #F6B73C
- Caramel: #C77B30
- Cocoa: #5B351F
- Brown: #3B2416
- Danger: #C4513B
- Success: #5F9E57

Typography:
- Readable first
- Friendly headings
- Avoid overly childish fonts
- Prefer consistent sizing across screens

UI style:
- Rounded cards
- Soft shadows
- Warm gradients
- Subtle polka dots, stripes, paper texture, or flour speckles
- Pixel art pastry sprites
- Crisp sprite rendering where possible
- Soft animations
- Cozy oven glow

UI patterns:
- Cards should feel like recipe cards or bakery labels.
- Active items should feel like stickers or tickets.
- Tag pills use coloured dots.
- Buttons are rounded, warm, tactile, and high contrast enough to read.
- Empty states should be encouraging, not sarcastic or hostile.
- Expired pastry copy should be demotivating but not cruel.

Android-specific guidance:
- Design for one-handed phone use first.
- Keep timer controls reachable near the lower half of the screen where practical.
- Avoid distracting motion during active study sessions.
- Use React Native Reanimated for oven warmth, pastry bounce, and page transitions.
- Respect reduced motion where the platform exposes it.
- Use sprites before icon fonts. Use FontAwesome only for missing generic actions.

Core screen visual priorities:
- Welcome: bakery warmth, croissant/app icon, clear start/login path.
- Dashboard: friendly username greeting, selected pastry, coins, study totals, quick actions.
- Timer setup: duration, tag, pastry, reward preview.
- Active timer: oven first, readable timer text, subtle animation, clear pause/cancel controls.
- Bakery: shelf or display-case layout with completed pastries grouped by type.
- Shop: clear locked/unlocked state, price, select active pastry.
- Stats: readable cards, tag bars with colour dots, most baked pastry sprite.
