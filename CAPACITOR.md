# Procrastibaker — mobile (Capacitor) shell

The web app is wrapped with [Capacitor](https://capacitorjs.com) so the exact same
React/Vite build runs as a native Android app (iOS can be added the same way).
Capacitor serves the built `dist/` inside a native WebView, so ~all of the UI,
Firebase, and game logic is shared with the web.

## What's in the repo
- `capacitor.config.ts` — app id (`com.procrastibaker.app`), name, `webDir: dist`,
  theme colours, splash config.
- `android/` — the generated native Android project (committed). Built assets and
  Gradle output are git-ignored and regenerated by `cap sync`.
- `src/utils/capacitor.ts` — `isNativeApp()` + `initNativeShell()` (status bar
  tint + hide splash). No-ops on web.
- Plugins installed: `@capacitor/app`, `@capacitor/status-bar`,
  `@capacitor/splash-screen`.

## Prerequisites
- Node + npm (already used for the web app).
- **Android Studio** (Giraffe+), a JDK 17, and the Android SDK — needed to build
  and run the native app. Not required for the web build.

## First-time setup after cloning
```bash
npm install
npm run build              # produces dist/
npx cap sync android       # copies dist/ + plugins into android/
```

## Run on a device / emulator
```bash
npm run cap:android        # build + sync + open Android Studio
```
Then press **Run ▶** in Android Studio. Or build a debug APK from the CLI:
```bash
cd android && ./gradlew assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

## Everyday workflow
After changing web code, re-copy it into the native app:
```bash
npm run cap:sync           # = npm run build && cap sync
```
(`cap copy` alone just copies web assets; `cap sync` also updates native plugins.)

### Live reload during development
Run the dev server on your LAN and point the shell at it (do **not** commit this):
```bash
npm run dev -- --host      # note the Network URL, e.g. http://192.168.1.20:5188
```
Add to `capacitor.config.ts`, then `npx cap sync android`:
```ts
server: { url: "http://192.168.1.20:5188", cleartext: true }
```

## Known follow-ups (important)
These are expected for a first shell — the web build is unaffected:

1. **Google sign-in** uses `signInWithPopup`, which does **not** work in a native
   WebView. Email/password sign-in, Firestore, streaks, friends, etc. all work.
   To enable native Google auth, add
   [`@capacitor-firebase/authentication`](https://github.com/capawesome-team/capacitor-firebase)
   and branch on `isNativeApp()` in `src/utils/authService.ts`.
2. **App Check (reCAPTCHA v3)** is browser-oriented. On Android, switch to the
   Play Integrity provider and register the app's SHA-256 + `capacitor://localhost`
   / `https://localhost` under Firebase App Check, or App Check-gated calls may be
   rejected on device.
3. **Firebase authorized domains** — add `localhost` (and your custom scheme) under
   Auth → Settings → Authorized domains for auth flows to resolve on device.
4. **App icons / splash** — replace the placeholder assets in
   `android/app/src/main/res/` (e.g. via `@capacitor/assets`).
5. **Reminders** — the in-app daily reminder only fires while a tab/app is open.
   Native background push needs `@capacitor/push-notifications` + FCM and a send
   trigger; this shell is the right place to add it.
